# vexonsystem.com

Site da Vexon: sites, lojas virtuais e sistemas web sob medida, em Brasília.
HTML, CSS e JavaScript, sem etapa de build. Publicado pelo GitHub Pages.

## Estrutura

```
index.html            página inicial
404.html              página de erro
site-pronto/          preços e prazos de site
projetos/             projetos de demonstração
  fibra/              landing page
  grao-vivo/          página de venda
  traco-arquitetura/  site institucional de 4 páginas
  loja/               loja virtual (export estático do Next.js)
  sistema-os/         painel de ordens de serviço
  sistema-oficina/    redirecionamento antigo para sistema-os
pre/                  propostas individuais (fora do Google)
metricas/             painel interno (fora do Google)
assets/               estilos, scripts e imagens
```

Toda página nova leva `<script src="/assets/m.js" defer></script>` antes de `</body>`.
